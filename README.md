# SEKOOL Content

Marketing and content assets for [SEKOOL.my](https://sekool.my): 1-to-1 online classes for primary school students (KSSR/KSSM) with Cikgu from Sekolah Kebangsaan.

| Project | What it is |
|---------|-----------|
| [`sekool-explainer/`](sekool-explainer/) | A 48-second premium explainer for parents (1080p60, music + SFX). The rendered video is at [`sekool-explainer/output/sekool-explainer.mp4`](sekool-explainer/output/sekool-explainer.mp4). |
| [`sekool-ad-photos/`](sekool-ad-photos/PROMPTS.md) | Copy-paste AI image prompts for candid "shot on a parent's iPhone" ad photos: 24 scenes across different kids, families, homes and Cikgu, with usage rules for ads. |
| [`sekool-reels/`](sekool-reels/) | Three short 9:16 Reels ads (15 s, 12 s and 8 s) built from real customer photos. Only the code is committed; the photos and videos stay private. |
